PÁGINA DO INGRESSO + PÁGINA DE OBRIGADO — GABRIEL QUINTANILHA · AULÃO DE BLACK FRIDAY 2026
Site estático (HTML + CSS + JS). Não precisa instalar nada.

ESTRUTURA
- index.html ............ página de venda do ingresso
- obrigado/index.html ... página de obrigado (configurar como redirecionamento pós-compra nos 3 checkouts)
- style.css ............. visual (identidade padrão Black Friday Pier)
- app.js ................ troca automática dos lotes por data + contadores
- config.js ............. ÚNICO ARQUIVO A EDITAR: links de checkout dos 3 lotes, link do grupo, datas
- assets/ ............... fotos e arquivo de agenda (.ics)

COMO EDITAR OS LINKS
Abra config.js e troque:
  #CHECKOUT-LOTE-1 / #CHECKOUT-LOTE-2 / #CHECKOUT-LOTE-3 -> links reais de checkout
  #LINK-DO-GRUPO-DE-AVISOS -> link do grupo de WhatsApp
Depois de editar, aumente o número ?v=2 nos arquivos HTML (ex.: ?v=3) para o navegador não usar a versão antiga.
